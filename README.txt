LangFix 0.5.0
===============

โปรแกรมแก้การพิมพ์ผิดภาษาระหว่างแป้นพิมพ์ไทย Kedmanee และอังกฤษ QWERTY สำหรับ Windows 11
พัฒนาโดย Panuphong Bunkum

วิธีใช้
1. เปิด LangFix แล้วโปรแกรมจะอยู่ที่ System Tray มุมขวาล่าง
2. พิมพ์คำ แล้วกดคีย์ลัดเพื่อแปลงคำล่าสุดเป็นอีกภาษา (ค่าเริ่มต้น Shift + Backspace)
3. เลือกคีย์ลัดเองได้จากหน้าตั้งค่า หาก LangFix แก้ผิด ให้กดคีย์ลัดเดิมซ้ำทันทีเพื่อย้อนกลับ
4. เปิด “แก้อัตโนมัติ” จากหน้าตั้งค่าหรือเมนู System Tray โปรแกรมจะแก้คำที่มั่นใจสูงทันทีเมื่อพิมพ์ครบ โดยไม่ต้องกด Space
5. ดับเบิลคลิกไอคอน System Tray เพื่อเปิดหน้าตั้งค่า
6. หลังแก้คำ LangFix จะเปลี่ยนภาษาแป้นพิมพ์ให้ตรงกับข้อความ เพื่อให้พิมพ์ต่อได้ทันที
7. เลือก “ตรวจสอบการอัปเดต” จาก System Tray เพื่อเช็กรุ่นใหม่ได้ทุกเวลา
8. LangFix มีพจนานุกรมอังกฤษและไทยในตัว จึงไม่ต้องติดตั้ง RightLang เครื่องที่มี RightLang อยู่แล้วจะอ่านพจนานุกรมเดิมแบบ read-only เพิ่มเติม
9. เลือก “ส่งความคิดเห็น / แจ้งปัญหา” จาก System Tray เพื่อรายงานปัญหา ขอฟังก์ชันเพิ่ม หรือส่งความคิดเห็นถึงผู้พัฒนา

ความเป็นส่วนตัว
- ประมวลผลในเครื่องทั้งหมด
- เชื่อมต่อเว็บไซต์ LangFix เพื่อตรวจหมายเลขเวอร์ชันวันละครั้ง และเมื่อผู้ใช้เลือกส่งความคิดเห็นด้วยตนเองเท่านั้น
- ไม่บันทึกประวัติการพิมพ์ลงไฟล์

ข้อจำกัดของรุ่น 0.5.0
- ใช้ได้กับโปรแกรมที่มีระดับสิทธิ์เท่ากัน หากโปรแกรมปลายทาง Run as administrator ต้องเปิด LangFix ด้วยสิทธิ์เดียวกัน
- โหมดอัตโนมัติเน้นความมั่นใจสูงและอาจไม่แก้คำเฉพาะ ชื่อ หรือคำสแลงบางคำ
- แนะนำให้ปิดโหมดอัตโนมัติชั่วคราวขณะกรอกรหัสผ่าน โดยเฉพาะในเว็บเบราว์เซอร์
- คีย์ลัดแก้ “คำล่าสุดที่เพิ่งพิมพ์” ยังไม่รองรับการเลือกข้อความหลายคำในรุ่นนี้
